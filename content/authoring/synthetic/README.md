# Synthetic DEV MaterialSets

**SYNTHETIC / DEV / NOT OFFICIAL MATERIAL**

Season `dev-synthetic-s3` exists only to exercise the Sprint 3 Phase 2A.1 content pipeline.

- Five independent workbooks: Cadet, Beginner, Junior, Intermediate, Experienced
- Fabricated `SynTest` references — not official WPF Scripture or Board files
- Intentionally repeats the same Scripture reference and local `cardId` across MaterialSets
- Includes repeated phrases, long/short text, optional quiz metadata, and cross references

Regenerate the `.xlsx` files with:

```bash
npm run content:write-authoring-files
```
